Valerie

A fast browser you change by asking. Spaces, pinned tabs, a command bar and vim keys, on Safari's engine, with agents that can see and use your browser.

Download for Mac
Apple silicon and Intel · macOS 14 or later · free

Install

One line in Terminal (the smoothest)

Downloads the latest Valerie, checks it's genuine, puts it in Applications and opens it.

curl -fsSL https://cullen-b.github.io/valerie/install.sh | bash
Homebrew

Valerie updates itself after that, so there's no need to brew upgrade it.

brew install --cask cullen-b/valerie/valerie
Download

Open the disk image and drag Valerie to Applications. Linux and Windows builds are on the releases page.

The first time you open a downloaded or Homebrew copy, macOS may say it can't check Valerie for malware (Valerie isn't notarized by Apple yet). Click Done, then open System Settings › Privacy & Security and click Open Anyway. That's once; updates after that install themselves. The Terminal line doesn't need this.

Why Valerie

Change anything by askingEvery setting lives in one readable file, written so an AI can edit it for you.
Agents built inChats that can open tabs, read pages and do the clicking, with the access you choose.
Arc's best ideasSpaces, pinned tabs and folders, a command bar, little windows and split view.
Fast and lightRust on the system's own web engine: Safari's speed and battery life on a Mac.
Syncs through GitHubSettings and tabs on every machine, in a private repo you own.
Updates itselfNew versions install quietly and start the next time you open Valerie.
